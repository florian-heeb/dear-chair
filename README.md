# Dear Chair

An interactive, click-through explanation of the paper at https://papers.ssrn.com/sol3/papers.cfm?abstract_id=4711873.

`index.html` is the page GitHub Pages serves. It is a build output: a copy of `dear_chair.html`,
generated from the paper's replication files by `Outreach/Explorable/build_explorable.R` in the
project repository. Do not edit it by hand.
